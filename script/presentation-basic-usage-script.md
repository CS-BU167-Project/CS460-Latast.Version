# Script พูด Present Project: การใช้งานหน้าเว็บเบื้องต้น

## ชื่อโปรเจกต์

สวัสดีครับ วันนี้ผมจะนำเสนอโปรเจกต์ **AI Smart Research Assistant** หรือในหน้าเว็บใช้ชื่อว่า **Smart Digest** ครับ

โปรเจกต์นี้เป็นเว็บแอปที่ช่วยให้ผู้ใช้สรุปและวิเคราะห์ข้อมูลจากหน้าเว็บได้ง่ายขึ้น โดยผู้ใช้แค่วาง URL ของบทความหรือหน้าเว็บที่ต้องการ จากนั้นใส่คำสั่งว่าต้องการให้ AI วิเคราะห์แบบไหน ระบบก็จะดึงเนื้อหาจากเว็บนั้น แล้วส่งให้ AI สรุปออกมาเป็นรูปแบบที่อ่านง่ายครับ

## เป้าหมายของโปรเจกต์

ปัญหาที่โปรเจกต์นี้แก้คือ เวลาเราต้องอ่านบทความยาวๆ หรือข้อมูลจากเว็บไซต์หลายหน้า อาจใช้เวลานานในการจับใจความสำคัญ

ดังนั้นระบบนี้จึงช่วยลดเวลาในการอ่าน โดยทำหน้าที่เป็นผู้ช่วยวิจัยเบื้องต้น สามารถสรุปเนื้อหา ดึง key takeaways วิเคราะห์ประเด็นสำคัญ หรือจัดผลลัพธ์ให้อยู่ในรูปแบบที่เหมาะสำหรับนำไปใช้ต่อได้ครับ

## ภาพรวมหน้าเว็บ

เมื่อเปิดหน้าเว็บขึ้นมา ผู้ใช้จะเห็นหน้าหลักของ Smart Digest ซึ่งมีส่วนสำคัญอยู่ไม่กี่ส่วนครับ

ส่วนแรกคือช่องสำหรับใส่ URL ของเว็บไซต์หรือบทความที่ต้องการวิเคราะห์

ส่วนที่สองคือช่องสำหรับใส่ prompt หรือคำสั่ง เช่น ให้สรุปบทความ ให้เน้นประเด็นสำคัญ ให้เปรียบเทียบ หรือให้สรุปสำหรับนำเสนอ

นอกจากนี้ยังมีปุ่มตัวอย่าง prompt ให้เลือกใช้งานได้ทันที ทำให้ผู้ใช้ไม่จำเป็นต้องคิดคำสั่งเองตั้งแต่ต้นครับ

## ขั้นตอนการใช้งาน

ขั้นตอนแรก ให้ผู้ใช้คัดลอก URL ของบทความหรือหน้าเว็บที่ต้องการวิเคราะห์ แล้วนำมาวางในช่อง URL

จากนั้นเลือกหรือพิมพ์คำสั่งที่ต้องการ เช่น "สรุปเนื้อหาหลักให้เข้าใจง่าย" หรือ "เน้นหลักสำคัญและคำศัพท์เทคนิค"

ถ้าต้องการเปลี่ยนภาษา สามารถกดปุ่มสลับภาษาได้ โดยหน้าเว็บรองรับทั้งภาษาไทยและภาษาอังกฤษ

หลังจากกรอกข้อมูลครบแล้ว ให้กดปุ่มเริ่มวิเคราะห์ ระบบจะแสดงสถานะว่ากำลังประมวลผลอยู่

## สิ่งที่เกิดขึ้นหลังจากกดวิเคราะห์

เมื่อผู้ใช้กดวิเคราะห์ หน้าเว็บจะส่ง URL, prompt และภาษาที่เลือกไปยัง backend

ฝั่ง backend จะดาวน์โหลดหน้าเว็บและดึงเนื้อหาหลักออกมา โดยตัดส่วนที่ไม่จำเป็น เช่น comment หรือ noise อื่นๆ ออก

หลังจากนั้น backend จะนำเนื้อหาที่ scrape ได้ไปรวมกับ prompt ของผู้ใช้ แล้วส่งไปยัง AI model เพื่อให้สร้างผลลัพธ์สรุปกลับมา

เมื่อได้ผลลัพธ์แล้ว หน้าเว็บจะแสดงเนื้อหาในรูปแบบที่อ่านง่าย เช่น มีหัวข้อ มี bullet point และมีส่วนสรุปสั้นๆ ครับ

## ฟีเจอร์ Export

หลังจากได้ผลลัพธ์แล้ว ผู้ใช้สามารถนำผลลัพธ์ไปใช้ต่อได้หลายแบบ

หน้าเว็บมีปุ่มสำหรับ export เป็น PDF และ PNG ซึ่งเหมาะสำหรับบันทึกเป็นเอกสาร ส่งงาน หรือใช้ประกอบการนำเสนอ

นอกจากนี้ยังมีปุ่ม copy เพื่อคัดลอกข้อความผลลัพธ์ไปใช้ต่อในเอกสารอื่นได้ด้วยครับ

## ตัวอย่างการ Demo

สำหรับการ demo ผมจะเริ่มจากเปิดหน้าเว็บ Smart Digest

ต่อมาผมจะวาง URL ของบทความตัวอย่างลงไปในช่อง URL

จากนั้นเลือก prompt เช่น "สรุปบทความ" เพื่อให้ระบบสรุปเนื้อหาหลักให้เข้าใจง่าย

หลังจากกดเริ่มวิเคราะห์ เราจะรอสักครู่ให้ระบบ scrape เนื้อหาจากหน้าเว็บ และให้ AI ประมวลผล

เมื่อผลลัพธ์แสดงขึ้นมา จะเห็นว่าระบบจัดเนื้อหาเป็นหัวข้อ มีสรุปสาระสำคัญ และมีรายละเอียดเป็นข้อๆ ทำให้อ่านง่ายกว่าการอ่านบทความเต็มโดยตรงครับ

สุดท้าย ผมจะแสดงการ export ผลลัพธ์เป็น PDF หรือ PNG เพื่อให้เห็นว่าสามารถนำผลลัพธ์ไปใช้งานต่อได้จริง

จุดเด่นของระบบคือใช้งานง่าย รองรับภาษาไทยและอังกฤษ และช่วยเปลี่ยนหน้าเว็บยาวๆ ให้กลายเป็นข้อมูลสรุปที่เข้าใจง่ายและนำไปใช้ต่อได้ทันทีครับ
