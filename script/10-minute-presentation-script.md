# Script Present Project เวอร์ชัน 10 นาที

## 0:00 - 0:45 เปิดการนำเสนอ

สวัสดีครับ วันนี้ผมจะนำเสนอโปรเจกต์ **AI Smart Research Assistant** หรือชื่อบนหน้าเว็บคือ **Smart Digest** ครับ

โปรเจกต์นี้เป็นเว็บแอปที่ช่วยให้ผู้ใช้วิเคราะห์และสรุปเนื้อหาจากหน้าเว็บได้ง่ายขึ้น โดยผู้ใช้แค่วาง URL ของบทความหรือเว็บไซต์ ใส่คำสั่งที่ต้องการ แล้วระบบจะ scrape เนื้อหาจากเว็บนั้น ส่งต่อให้ AI วิเคราะห์ และแสดงผลลัพธ์ออกมาในรูปแบบที่อ่านง่ายครับ

เป้าหมายหลักของโปรเจกต์คือช่วยลดเวลาการอ่านข้อมูลยาวๆ และช่วยให้ผู้ใช้ได้สรุปที่นำไปใช้ต่อได้ทันที เช่น ใช้สำหรับทำรายงาน อ่านบทความวิชาการ หรือเตรียมข้อมูลสำหรับการนำเสนอครับ

## 0:45 - 3:00 Demo การใช้งานหน้าเว็บ

ต่อไปผมจะอธิบายการใช้งานหน้าเว็บเบื้องต้นครับ

เมื่อเปิดเว็บขึ้นมา ผู้ใช้จะเห็นหน้า Smart Digest ซึ่งมีส่วนหลักๆ คือช่องใส่ URL ช่องใส่ prompt หรือคำสั่ง และปุ่มสำหรับเริ่มวิเคราะห์

ขั้นตอนแรก ผู้ใช้คัดลอก URL ของบทความหรือหน้าเว็บที่ต้องการวิเคราะห์ แล้วนำมาวางในช่อง URL

ขั้นตอนที่สอง ผู้ใช้พิมพ์คำสั่งว่าต้องการให้ AI ทำอะไรกับเนื้อหานั้น เช่น "สรุปบทความให้เข้าใจง่าย" หรือ "เน้นประเด็นสำคัญและคำศัพท์เทคนิค"

ในหน้าเว็บยังมี quick prompt ให้เลือกด้วย ทำให้ผู้ใช้สามารถกดเลือกคำสั่งสำเร็จรูปได้ทันที โดยไม่จำเป็นต้องเขียน prompt เองทั้งหมด

นอกจากนี้ระบบยังรองรับทั้งภาษาไทยและภาษาอังกฤษ ผู้ใช้สามารถกดปุ่มสลับภาษาได้ตามต้องการ

หลังจากกรอกข้อมูลครบแล้ว ให้กดปุ่มเริ่มวิเคราะห์ ระบบจะแสดงสถานะ loading เพื่อบอกว่ากำลังประมวลผล

เมื่อประมวลผลเสร็จ ผลลัพธ์จะแสดงบนหน้าเว็บในรูปแบบที่อ่านง่าย มีหัวข้อ มี bullet point และมีส่วนสรุป ทำให้ไม่ต้องอ่านเนื้อหาทั้งหมดจากหน้าเว็บต้นฉบับ

หลังจากได้ผลลัพธ์แล้ว ผู้ใช้ยังสามารถคัดลอกข้อความ หรือ export ผลลัพธ์เป็น PDF และ PNG ได้ด้วย ซึ่งเหมาะสำหรับนำไปส่งงานหรือใช้ประกอบการนำเสนอครับ

## 3:00 - 6:30 Workflow การ Scrape และประมวลผล

ต่อไปเป็น workflow ของระบบครับ

ระบบเริ่มจากฝั่ง frontend ซึ่งสร้างด้วย React และ Vite ผู้ใช้กรอก URL, prompt และภาษาที่ต้องการ จากนั้นกดปุ่มเริ่มวิเคราะห์

เมื่อกดปุ่มแล้ว frontend จะส่ง request ไปที่ path `/myai/api/analyze` โดยส่งข้อมูลเป็น JSON ได้แก่ `url`, `prompt` และ `lang`

ในตอน development Vite จะทำหน้าที่ proxy request จาก `/myai/api` ไปยัง backend ที่รันอยู่บน `localhost:8000` และ backend จะรับ request จริงที่ endpoint `/api/analyze`

เมื่อ backend ได้รับ request แล้ว ขั้นแรกจะตรวจสอบว่าในไฟล์ `.env` มี `GROQ_API_KEY` หรือไม่ ถ้าไม่มี ระบบจะส่ง error กลับไป เพราะไม่สามารถเรียก AI model ได้

ถ้ามี API key ระบบจะเริ่มขั้นตอน scrape โดยใช้ไลบรารี `trafilatura`

ขั้นแรกคือ `trafilatura.fetch_url(url)` ใช้สำหรับดาวน์โหลด HTML จากหน้าเว็บที่ผู้ใช้ใส่เข้ามา

ถ้าดาวน์โหลดไม่ได้ เช่น URL ผิด เว็บล่ม หรือเว็บไซต์บล็อกการเข้าถึง ระบบจะส่ง error กลับไปยังหน้าเว็บ

ถ้าดาวน์โหลดสำเร็จ ขั้นต่อไปคือ `trafilatura.extract()` เพื่อดึงเฉพาะเนื้อหาหลักจาก HTML ออกมา

จุดสำคัญคือขั้นตอนนี้ช่วยลด noise จากหน้าเว็บ เช่น menu, comment หรือส่วนอื่นๆ ที่ไม่ใช่เนื้อหาหลัก ทำให้ข้อมูลที่ส่งให้ AI สะอาดขึ้น

หลังจากได้ text content แล้ว backend จะสร้าง prompt ฉบับเต็ม โดยรวม instruction ของระบบ, prompt ที่ผู้ใช้กรอก, ภาษาที่เลือก และเนื้อหาที่ scrape ได้เข้าด้วยกัน

จากนั้น backend จะส่ง prompt นี้ไปยัง Groq API โดยใช้ OpenAI SDK และเรียกโมเดล `llama-3.1-8b-instant`

เมื่อ AI สร้างคำตอบกลับมา backend จะส่งผลลัพธ์กลับไปยัง frontend เป็น JSON

สุดท้าย frontend จะนำผลลัพธ์มา parse และ render ให้สวยงาม เช่น แปลง heading, bullet point, table และ code block ให้อยู่ในรูปแบบ HTML ที่อ่านง่ายครับ

## 6:30 - 8:30 Tech Stack หลัก

ต่อไปเป็น tech stack หลักของโปรเจกต์ครับ

ฝั่ง frontend ใช้ **React** สำหรับสร้าง user interface และจัดการ state เช่น URL, prompt, language, loading state และ result

ใช้ **TypeScript** เพื่อช่วยให้โค้ดมี type safety มากขึ้น

ใช้ **Vite** เป็น development server และ build tool รวมถึงใช้ proxy request ไปยัง backend ในตอน development

ใช้ **Tailwind CSS** สำหรับ styling และ layout ของหน้าเว็บ

ใช้ **Lucide React** สำหรับ icon ต่างๆ เช่น ปุ่ม export, copy และ loading

นอกจากนี้ยังใช้ **html2canvas** และ **jsPDF** สำหรับ export ผลลัพธ์เป็นรูปภาพและ PDF

ฝั่ง backend ใช้ **Python** และ **FastAPI** สำหรับสร้าง REST API

ใช้ **Uvicorn** สำหรับรัน FastAPI server

ใช้ **Pydantic** สำหรับกำหนด request schema ว่าต้องรับ `url`, `prompt` และ `lang`

ส่วนการ scrape ใช้ **Trafilatura** ซึ่งเหมาะกับการดึงเนื้อหาหลักจากหน้าเว็บ

สำหรับ AI provider โปรเจกต์นี้ใช้ **Groq** แต่เรียกผ่าน **OpenAI SDK** เพราะ Groq รองรับ OpenAI-compatible API

โมเดลที่ใช้คือ:

```text
llama-3.1-8b-instant
```

โมเดลนี้ทำหน้าที่รับเนื้อหาที่ scrape ได้พร้อมกับ prompt ของผู้ใช้ แล้วสร้างคำตอบเป็นบทสรุปหรือบทวิเคราะห์กลับมาครับ

## 8:30 - 9:30 จุดเด่นของระบบ

อย่างที่สองคือระบบแยกหน้าที่ชัดเจน frontend ดูแลการรับ input และแสดงผล ส่วน backend ดูแลการ scrape และเรียก AI model

## 9:30 - 10:00 สรุปปิดท้าย

สรุปคือ **AI Smart Research Assistant** เป็นเว็บแอปที่ช่วยเปลี่ยนหน้าเว็บหรือบทความยาวๆ ให้กลายเป็นข้อมูลสรุปที่อ่านง่าย

ระบบทำงานโดยรับ URL และ prompt จากผู้ใช้ จากนั้น backend ใช้ Trafilatura scrape เนื้อหาหลัก แล้วส่งต่อให้ Groq model `llama-3.1-8b-instant` วิเคราะห์ ก่อนแสดงผลกลับมาที่หน้าเว็บ

โปรเจกต์นี้จึงเหมาะกับการช่วยอ่าน ช่วยสรุป และช่วยเตรียมข้อมูลสำหรับการเรียนหรือการนำเสนอครับ
